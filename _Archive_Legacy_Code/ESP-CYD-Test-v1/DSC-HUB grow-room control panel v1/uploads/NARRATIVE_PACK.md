## The arc
**Absurdity → Philosophy → Capability → Emotion → Independence → Poetry → Economics → Resourcefulness → Future → Mission.**

Each chapter answers one question a stranger would ask, in order:
what's wrong with the market? → what do you believe? → what does it do? → why should I care? → what if things break? → is it actually good? → what does it cost? → what if I'm broke? → what's next? → why does any of this matter?

Every image carries a `CH.xx / 10` mark — it signals a series without demanding one. Post them in order, out of order, or one at a time; each closes its own loop.

## Ethos, codified (so future content stays on-message)
1. **The base product is complete.** Nothing about the ecosystem may imply the Hub is unfinished without it. "Want, never need" is a hard rule in copy.
2. **No price gate on knowledge.** Firmware, guides, and parts lists stay free. The only paid thing is convenience (pre-built V3).
3. **Brand agnostic, mechanism-first.** "A fan is a fan" — we talk about what gear *does*, never what badge it wears.
4. **Resourcefulness is celebrated, not tolerated.** The Dumpster Edition is a flagship, not a footnote.
5. **Local first, always.** The room owns its own brain and its own data (Trend box). The cloud is a punchline, not a dependency.
6. **The mission outranks the market.** Grow-food-anywhere is the north star; cannabis was the proving ground *because* it's the hardest case.
