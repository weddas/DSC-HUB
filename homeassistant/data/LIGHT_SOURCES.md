# Light data sources

- `dsc_light_pack_photometrics.yaml`: curated starter inventory with stated
  fixture metrics and manufacturer map/document URLs.
- `dsc_lights_*.json`: optional local source dumps used by the search indexer.

The YAML pack is the retained MVP source. It is not a complete light-market
crawl. PPFD and spectrum values are only included when stated or linked; no
heatmap cells are inferred.
