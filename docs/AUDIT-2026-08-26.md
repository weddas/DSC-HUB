## 5. Root-cause record (ingest bugs fixed this pass)

| Symptom | Cause | Fix |
|---|---|---|
| Ladder chips always `0` / idle | `HUB_SENSOR_OID_TO_KEY` missing `*_fire_countdown` slugs | Dual slug + legacy maps in `hub_controls.py` |
| Fans always 0% | Fan object_ids like `4_inch_intake_fan__main_` unmapped | `HUB_FAN_OID_TO_ENTITY` expanded |
| Full Auto / photoperiod “Standby” | `tent_full_auto_mode`, `auto_photoperiod` slug mismatch | Switch map dual keys |
| SF1000 state invisible | `sf1000_dimmer` vs `light_sf1000` | Light map |
| Firmware chip wrong | Read ESPHome framework version | `_hub_text_sensors_from_states()` → `firmware_version` |
| Stale Pi UI after deploy | `force-recreate` without image rebuild | `deploy-brain-remote.sh` tries `docker compose build` first |
